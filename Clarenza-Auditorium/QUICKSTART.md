# Crystal Codex desktop pilot — launch guide

1. Extract the complete release ZIP.
2. Open Clarenza-Auditorium and run Launch.cmd. Close any older launcher first.
3. Sign in with your existing local account. Accounts are stored outside the application folder and remain available on this computer.
4. Open a published class, or import material as a teacher / in private study mode.
5. In class, use Learning book or B to open the Crystal Codex. Use its left page to select Transcript, Notes, AI tutor or Practice. Use Close Codex or the bottom book button to close it. B is intentionally inactive while typing in Notes or AI tutor.
6. Browser / YouTube pauses narration and opens the existing separate desktop browser. Resume the lecture manually after returning.
7. Live AI requires Launch-With-AI.cmd and your locally entered API credentials. No API key is included in this release.

This release restores the original suited teacher asset and introduces a functional 3D Codex shell. It is a desktop interaction prototype, not the finished concept-art asset or a headset implementation. It preserves the original auditorium and existing teacher/student permission system.

Roaming teacher: launch, enter a lesson and press Play. After the initial gesture and a short delay, the teacher chooses a stair route and returns between trips. Use Teacher: roaming / Teacher: stationary to toggle movement. Pausing the lecture also pauses walking. Voice originates at the moving teacher's head; headphones are recommended for evaluating left/right positioning.

Coordinated teacher: narration begins after the tablet gesture and slide reveal. The slide remains fully readable. Automatic passages include six seconds of reading time, when roaming can resume. Focus mode or Board focus requests a walk back to the teaching area during silent intervals; it does not teleport the teacher. Pause and stationary mode also pause that return.

Two-class release: teachers can Save unpublished draft or Approve reviewed lesson, publish and enter. Revise creates a new version. Students use Create a private AI class / study lesson; enter topic, level, duration and language, with source text or matching teacher-approved catalog material. AI requires local key/model setup via Launch-With-AI.cmd. Progress resumes by passage on this computer.

Read aloud: choose Read aloud / Export audio in the lobby or Codex. Paste text or load a passage, notes or tutor answer; choose speed, then Listen. Pause/Resume/Stop and Export WAV are available. Closing stops personal playback; resume the lecture manually. No paid API is required.

Home: Explore classes opens teacher-published lessons. Start a private class opens your personal creation form. Use My library for private lessons/drafts, Study tools for browser/audio/lab, and Account & settings for sign-out and admin provisioning. Teachers also see Teacher studio.
